# 09 — Исправления по ревью 08

Метод: superpowers:brainstorming, путь «ограниченная задача» (правки существующих экранов). Владелец недоступен — вопросы решены по ревью, выбран рекомендуемый вариант.

## Решения

1. **Карточка лида (`leads.js`, вид `lead`).** Вверху карточки — закреплённая панель (`position: sticky`):
   выбор предложения (4 чипа) + «Копировать» + «Написать в Telegram»; статусы (те же 7); «← Пред.» / «След. →» по текущему списку «Лидов» (порядок и фильтр `L.items`, при конце страницы догружается следующая).
   После выбора статуса по умолчанию открывается следующий лид; переключатель «Дальше после статуса» хранится в `localStorage` (`lem.leads.autoNext`, в try/catch). При «Отказ» тост «Удалить» относится к тому лиду, которому поставили статус.
   4 предложения с «Копировать» остаются в блоке «Предложения». Чистая логика соседей/подписей — в `lead-nav.js` (тест в `tests/desktop-ui.test.cjs`).
2. **Сегодня.** После «Понятно» предупреждение — одна строка «Холодные сообщения: риск блокировки…» с «Подробнее»; свёрнутость = `acknowledged` из сервиса (уже хранится). Пустая очередь: сервиса «взять N новых» нет (есть только `outreach_add` по одному) — кнопки «Открыть новые лиды» и «Новый поиск».
3. **Строка «Лидов».** Мета собирается через `filter(Boolean).join(' · ')`; тип сайта словами, включая `own_site` → «Свой сайт».
4. **«Назад».** Скрыт на корневых разделах меню (кроме «Медиа», открытой из карточки); подпись по месту возврата: «← К лидам», «← К «Сегодня»», иначе «← Назад». Низ меню: «Данные: локально», полный путь — в `title`.
5. **Мелочи.** Кнопки «Сохранить» в Настройках выравниваются по низу поля; `own_site` и др. коды в «Итогах» → слова; время в истории «Поиска» → `31.10, 09:04` (локальное); поле «Отзывы» в Поиске получало строку `${...}` без интерполяции — исправлено, берётся из Настроек.
