# 05 · Настройки

Запрос владельца: убрать «Обзор» и все служебные заметки, вернуть тему, все ключи, полезные ручные настройки, из данных — только импорт.
Владелец недоступен; решения приняты по рекомендованным вариантам.

## Экран (app/desktop_ui/settings.js)
1. **Оформление** — Светлая / Тёмная / Как в системе.
2. **Ключи** — OpenRouter (панель ai.js, переносится в группу) и Telegram API для рассылки: статус (api_id маской), заменить, удалить. Значения не показываются, поле очищается сразу после отправки.
3. **Работа** — «Отзывов на организацию по умолчанию» (подставляется в форму поиска) и «Сообщения «Сегодня»» (today.js).
4. **Рассылка** — точка монтирования `#settings-mailing`; блок `mailingSettingsBlock(el)` даёт mailing.js (другой агент). Без функции группа скрывается.
5. **Данные** — «Импорт базы (XLSX)», «Импорт SQLite», «Открыть папку с данными».

Убрано из интерфейса (сервисы остались): «Обзор», баннер старой копии, заметки про Telegram/Python, путь каталога, резервная копия, экспорт, «Заменить базу…», логи, HTML-диагностика.
Выбор модели ИИ не добавлен: модели задаются только переменной окружения, отдельной настройки нет.

## Тема
- Хранится в `desktop_settings.ui_theme` (`services.ui_settings` / `ui_settings_save`, там же `search_review_limit`).
- desktop.py открывает страницу с `#theme=<pref>` (query `?` ломает загрузку file:// в pywebview) и задаёт фон окна; скрипт в `<head>` ставит `html[data-theme]` до первой отрисовки, запасной источник — localStorage.
- Тёмная палитра — из Mini App (`lead-mini-app/app/desktop_ui/dark.css`), все токены переопределены в `lem.css` под `:root[data-theme="dark"]`; новый токен `--on-accent` для текста основной кнопки.
- `scripts/check_desktop_theme.py` проверяет, что тёмный блок перекрывает все цветовые токены, и контраст в обеих темах.

## Ключи Telegram
`MailingService.clear_keys()` + мост `mailing_clear_keys`; сохранение — существующий `mailing_save_keys`.
