# 06 · Ровные поля формы «Новый поиск» и похожие баги вёрстки

Путь: bounded (правка существующей вёрстки). Владелец недоступен — решения приняты по его требованиям.

## Корневая причина
`label.field` — это `display:grid` без `align-content`. В `.form-grid` (тоже grid, `align-items: stretch` по умолчанию)
каждая ячейка растягивается до высоты самой высокой в ряду (textarea «Города» с `min-height:110px`), а внутренний
grid подписи раздаёт лишнюю высоту своим авто-строкам — поэтому select/input вырастали до ~85px, а разная длина
подписей сдвигала поля по вертикали. Прежние «исправления» правили высоты, но не это растяжение, поэтому баг возвращался.

## Решение
- В конце style.css блок «Layout guard»: `.form-grid{align-items:end}`, `label.field{align-content:start}`,
  единая высота `input/select` в `.field` = 42px (`height`, не только `min-height`), textarea в форме — 42–120px, растёт вниз.
- Подписи короткие и в одну строку (`white-space:nowrap; text-overflow:ellipsis`); пояснения — `<small>` под полем.
  «Города (через запятую…)» → «Города» + подсказка; подсказка «Отзывы…» не влияет на верх поля, т.к. ряд выравнивается
  по полю (`.field > small` в последней строке, поля — во второй строке через `grid-template-rows:auto 42px auto`).
- Узкая ширина: 2 колонки ≤1100px, 1 колонка ≤640px (уже было для 900/… — проверено).
- Карточка: `overflow-wrap:break-word` вместо `anywhere` (не рвёт слова посреди без нужды).
- Регрессия: node-тест на CSS-правила + UI-замер getBoundingClientRect.
