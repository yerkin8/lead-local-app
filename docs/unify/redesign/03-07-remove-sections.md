# Пункты 3 и 7: убрать разделы «База» и «Панель»

Путь brainstorming: bounded (меняем существующую навигацию). Владелец недоступен — решения приняты по его требованиям.

## Решение
- Из сайдбара убираются `data-view="dashboard"` («Панель») и `data-view="businesses"` («База»). Приложение стартует на «Лидах» (`state.view='leads'`).
- Удаляется код: `dashboard()` и `businesses()` в app.js и их обёртки в flows.js, иерархия ниша → город → запуск (flows.js), glass-folder.js/.css, base-поля истории в stage9.js, пункты «Обзор»/«Папки поисков» в «Ещё» (leads.js), блок «Обзор» в today.js.
- Данные остаются в SQLite в папке данных. Кнопку «Открыть папку с базой» добавит владелец раздела «Настройки» (другой агент).
- Сервисы Python (`businesses`, `parse_runs`, `export_scope`…) не трогаем: ими пользуются ИИ-чат, Медиа, Лиды и тесты.

## Где теперь то, что было только в «Базе»
| Что | Где |
|---|---|
| Карточка (detail/telegram) | «Лиды» → «Старый вид карточки», «Сегодня», «Итоги», результаты поиска («Новые организации задания»); подсветка в сайдбаре — «Лиды» |

| Медиа | меню карточки в «Лидах», раздел «Медиа», кнопка «Медиа» в карточке |
| Импорт/экспорт XLSX | «Настройки» (уже были) |
| Экспорт по нише/городу/запуску | убран вместе с папками (экспорт всей базы остаётся в «Настройках») |
