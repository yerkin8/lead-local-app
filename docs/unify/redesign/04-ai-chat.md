# Редизайн 04 — «ИИ-чат» как настоящий чат

Запрос владельца: «ИИ-чат должен быть построен как ИИ-чат… убрать плашку „опишите, какое сообщение нужно“ вообще. Оставить только выбор типа сообщения и бизнеса», белая и тёмная тема, по образцу React-компонента AIChatCard.

## Что сделано
- Карточка чата на всю высоту контента: шапка («ИИ-чат», «Чем помочь сегодня?», круглая кнопка сброса с вращающейся иконкой), лента сообщений, композер внизу.
- Пузыри: пользователь справа (тёмный), ИИ слева; под ответом «Копировать», «В скрипты», модель и время, быстрые уточнения «Короче / Другой вариант / Начни с …». «Вставить в карточку» не добавлено — такого действия в приложении нет.
- Ожидание: пузырь «печатает… N с» с тремя точками. Ошибки — красным пузырём в ленте, текст возвращается в поле ввода.
- Пустое состояние: плавающая иконка, приветствие по времени суток, короткая подсказка. Плашки «Опишите…» и кнопок-примеров больше нет; примеры печатаются «печатной машинкой» в пустом композере (48/14/3400/900 мс), клик в поле превращает показанный пример в редактируемый текст.
- Композер: авторазмер textarea (44–200 px), Enter — отправить, Shift+Enter — новая строка. В нижней строке композера два селектора-«чипа»: тип сообщения (нативный select) и бизнес (поповер с поиском, Enter выбирает первый, Esc закрывает).
- Нет ключа: в ленте понятное приглашение и кнопка «Открыть настройки»; композер выключен. `settingsKeyBlock` (блок ключа в «Настройках») не изменён по поведению; в него добавлена ссылка на страницу ключей OpenRouter.
- Темы: только CSS-переменные. Собственные `--ai-*` в ai.css берут светлые значения из токенов lem.css, под `:root[data-theme="dark"]` — из всегда тёмных токенов `--log-bg/--log-text` через `color-mix` (литералов цвета нет, check_desktop_theme.py зелёный).
- `prefers-reduced-motion`: анимации и машинка отключаются, показывается один пример неподвижно.

## Решения (DECISIONS)
- **Не React.** Desktop — pywebview/WebView2 с ванильным JS без npm и сборки, обязан работать офлайн и из исходников; React+Tailwind+motion потребовал бы сборочный конвейер, бандл и второй способ рендера рядом с существующим `render()`. Дизайн и поведение образца перенесены вручную: CSS-анимации вместо motion, inline SVG в стиле lucide (refresh-cw, message-circle-dashed, plus, arrow-up, copy, bookmark, tag, x) вместо lucide-react.
- Чистая логика вынесена в `ai-core.js` (без DOM) — её покрывает `tests/ai-chat.test.cjs`.
- «+» из образца (вложения) не нужен — на его месте чипы типа и бизнеса.
- Таймеры — цепочки `setTimeout` (в Desktop запрещены независимые интервалы).
