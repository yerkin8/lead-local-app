**E-M-05** · Кликабельность ссылок · чтение telethon_gateway.py:222–230: `SendMessageRequest(peer, text, no_webpage=True, random_id)`,
`entities` не передаются, предпросмотр выключен. По документации Telegram (core.telegram.org/api/entities, раздел
«Autogenerated entities») сервер сам создаёт `messageEntityUrl` для обычных URL в несекретных чатах — значит, голый
`https://…` должен быть кликабельным. Утверждение авторов (docs/prompts/NEXT-…md §5) «у получателя — обычный текст»

(`[слова](url)`) невозможна: `BRACKETS` (service.py:31, 425, 525) блокирует любые `[…]` как незаполненные поля.
Итог: **не проверено вживую**, по коду и документации — вероятно кликабельно · 2026-11-01

**E-M-19** · Правовые и ToS-риски · оценка по коду и нормам, без живых данных · 2026-11-01
- Telegram: массовые холодные сообщения незнакомцам с пользовательских аккаунтов через сторонний api_id — ровно то, что
  ToS/API Terms называют спамом. Механика последствий: жалобы «спам» → PEER_FLOOD (писать можно только взаимным
  контактам), заморозка/бан номера, теоретически бан api_id (заденет все аккаунты на нём). Модуль это учитывает
  (карантин, FloodWait, малые лимиты, «СТОП» в подвале, без маскировки устройства), но карантин снимается одной кнопкой
  (service.py:250–268), а E-M-08/E-M-10/E-M-11/E-M-14 дают повторные сообщения — главный ускоритель жалоб.
- 38-ФЗ ст.18 ч.1: реклама по сетям электросвязи — только с предварительного согласия адресата, бремя доказать согласие —
  на распространителе; ФАС практикует применение к мессенджерам. Шаблонное предложение услуг многим организациям с
  подстановкой названия может быть признано рекламой. Санкция — ч.1 ст.14.3 КоАП (для ИП как должностного лица — тысячи–
  десятки тысяч ₽, для юрлица — сотни тысяч ₽). Вероятность — низкая (нужна жалоба), но одна жалоба = дело.
- 152-ФЗ: телефоны и username ИП/самозанятых — персональные данные; ст.15 ч.1 требует предварительного согласия для
  продвижения услуг прямыми контактами; «общедоступность» в Яндекс.Картах согласия не заменяет. Плюс обязанности
  оператора (уведомление РКН, политика). Риск — проверка/штраф по ст.13.11 КоАП по жалобе.
- Наиболее вероятное последствие на практике — потеря аккаунтов Telegram, а не штрафы.
