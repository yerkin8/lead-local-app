# Локальные шрифты desktop-интерфейса

Шрифты используются без сетевых запросов при запуске приложения. WOFF2-поднаборы загружены 17 октября 2026 г. через официальный Google Fonts CSS API; в комплект включены латиница и кириллица, включая расширенные блоки.

- **Inter** — [каталог Google Fonts](https://github.com/google/fonts/tree/main/ofl/inter), лицензия `OFL-Inter.txt`.
- **JetBrains Mono** — [каталог Google Fonts](https://github.com/google/fonts/tree/main/ofl/jetbrainsmono), лицензия `OFL-JetBrainsMono.txt`.

Файлы сохраняют имена upstream-подмножеств, лицензии приложены рядом. Размеры и SHA-256 проверяются этапом сборки и файлами `VERIFICATION.md`.
