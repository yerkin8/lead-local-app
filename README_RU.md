# LeadEqualMoney Desktop

Локальное приложение для Windows 10/11 (x64). Ищет малый бизнес на Яндекс.Картах — без сайта, с сайтом
на конструкторе или с неработающим сайтом — и помогает написать им в Telegram с предложением сайта,
лендинга, бота, автоматизации, ИИ-агента или продвижения. Всё работает на вашем компьютере: база,
ключи и сессии Telegram никуда не отправляются.

Запуск: двойной щелчок по `LeadEqualMoney.exe` в папке `LeadEqualMoney` (папку держите целиком — рядом
лежат библиотеки). Python не нужен. Нужен Microsoft Edge WebView2 Runtime (в Windows 11 он есть).

## Разделы

| Раздел | Что в нём |
|---|---|
| **Лиды** | Стартовый экран. Вкладки «Новые / Напомнить / Написал / В диалоге / Все», фильтры по нише, городу, типу сайта, поиск. Карточка лида: 4 готовых предложения (сайт, лендинг, бот, продвижение) с «Копировать», «Написать в Telegram», статусы, «← Пред. / След. →». Кнопка «Разослать этой пачке» |
| **Итоги** | Воронка и статистика по статусам |
| **Сегодня** | Ручная отправка по ссылкам: очередь, дневной лимит, пауза, напоминания через 3 дня после «Написал» |
| **Поиск** | Новый поиск и история заданий с кнопкой «Остановить» |
| **Скрипты** | 97 текстов: продукт → этап разговора; правка на месте |
| **ИИ-чат** | Помощник по текстам (ключ OpenRouter — в «Настройках») |
| **Рассылка** | Аккаунты Telegram, кампании и пачки, стоп-лист, правила отправки, журнал |
| **Медиа** | Фото из галереи и товары организации |
| **Настройки** | Тема, ключи (OpenRouter, Telegram API), отзывов по умолчанию, тайминги рассылки, импорт базы |

## Как искать

1. «Поиск» → страна, город (можно несколько через запятую), ниша, сколько новых найти, типы сайта,
   «Отзывы на организацию» (0 — не собирать; по умолчанию из «Настроек»).
2. «Начать поиск». Поиск идёт в два прохода: сначала находит карточки до цели — они сразу появляются
   в «Лидах»; потом догружает отзывы и число фото («Карточки найдены, догружаю отзывы и фото: N из M»).
   Скорость: около 40–50 карточек в минуту на первом проходе (замеры — `verification/next/search-speed.txt`).
3. **Остановить**: кнопка у задания в очереди или в работе. Задание получает статус «Остановлен», всё
   найденное до остановки остаётся в «Лидах». Повторный поиск с теми же параметрами продолжит с новых карточек.
4. **Капча.** Если Яндекс показал проверку или ограничил запросы, задание получает статус «Капча — Яндекс
   ограничил, повторите позже». Приложение капчу не обходит; повторите поиск позже.

## Как работать с лидами

Откройте лид → выберите предложение → «Копировать» или «Написать в Telegram» → поставьте статус
(«Позвонить», «Написал», «Ответили», «В работе», «Договорились», «Отказ»). После статуса открывается
следующий лид. «Написал» через 3 дня попадает в напоминания раздела «Сегодня».

## Как устроена рассылка

- **Пачка.** «Лиды» → вкладка и фильтры → «Разослать этой пачке». Каждому лиду текст подставляется сам
  (название, город, ниша, тип сайта; скрипт под тип сайта). Запуск одной кнопкой со словом `ОТПРАВИТЬ`,
  можно сначала «Посмотреть тексты» (сухой запуск — ничего не отправляется).
- **Результат.** «Рассылка» → «Кампании» → кампания. Пачка — это первая рассылка и все её повторы.
  У каждого бизнеса видно: Отправлено / Не дошло / В стоп-листе / Пропущено / В очереди / Ответил,
  и его статус в «Лидах».
- **Статусы «Лидов».** После реальной отправки лид получает «Написал» и через 3 дня появляется в
  напоминаниях «Сегодня». Ответ в Telegram → «Ответили». Ответ «стоп» → «Не писать» и «Отказ».
  Ответы учитываются, пока приложение открыто.
- **Повторить пачку.** В кампании блок «Повторить пачку другим сообщением»: по умолчанию «Напоминание»
  (подставится каждому), можно выбрать любой скрипт. Повтор получают только те, кому сообщение дошло.
  Автоматически не попадают: ответившие, «Убран из пачки», стоп-лист, «Не писать», лиды со статусом
  «Ответили», «В работе», «Договорились», «Отказ». Сначала можно сделать сухой запуск повтора.
- **Пока не исправлено (REVIEW.md, R1–R2):** не делайте повтор одной пачки дважды, не повторяйте повтор и не
  запускайте две кампании на одних и тех же лидах одновременно — организация может получить сообщение дважды.
  Если лид ответил уже после создания повтора, уберите его из пачки до запуска.
- **Убрать из пачки** — кнопка у бизнеса (например, уже ответил в другом месте). В повторы он не попадёт,
  сообщение в очереди снимается. «Вернуть в пачку» отменяет это для следующих повторов.
- **Защита.** Слово `ОТПРАВИТЬ`, аварийный стоп, стоп-лист, «Не писать», лимиты в день и в час, паузы,
  окно отправки по времени получателя, FloodWait, карантин аккаунта и строка «СТОП» в каждом сообщении.
  Тестовый аккаунт пишет только тестовым адресатам.
- **Тайминги и количество** — «Настройки» → «Рассылка: тайминг и количество» (пауза между сообщениями,
  окно отправки, только будни, лидов в пачке, сообщений в день и в час).
- Кампания идёт, пока открыто окно; после перезапуска продолжается с того же места.

## Где лежат данные

- `%APPDATA%\LeadEqualMoney\app.sqlite3` — база лидов, скриптов, заданий.
- `%APPDATA%\LeadEqualMoney\mailing\` — кампании (`mailing.sqlite3`), ключи и сессии Telegram
  (зашифрованы вашей учётной записью Windows, папка доступна только вам).
- `%APPDATA%\LeadEqualMoney\backups\` — копии базы перед каждым обновлением схемы.
- `%APPDATA%\LeadEqualMoney\browser-profile\` — профиль браузера для медиа и запасного поиска через браузер (запоминает пройденную проверку).
- Ручные резервные копии перед установкой новой сборки — `Documents\backups\LeadEqualMoney-*`
  (`roaming\` — вся папка данных, `desktop-build\` — прежняя сборка).

## Сборка и проверка (для разработчика)

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify.ps1
```

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1
```

Сборка — `dist\LeadEqualMoney\`. Перед передачей: `scripts\mailing_leak_scan.py` (утечки ключей),
порядок установки на рабочий стол — `verification/redesign/install.txt`. Проверка окна:
`scripts\seed_demo_data.py` (DATA_DIR=`.build-tmp\ui-tour-data`) → `scripts\unify_ui_tour.py`.
Тесты запускаются интерпретатором `.build-venv`.

## Как обновить скрипты

1. Выгрузить все тексты в один файл:
   `.build-venv\Scripts\python.exe scripts\import_rewritten_scripts.py --export docs\scripts\scripts-for-rewrite.md`
2. Переписать тексты (подсказка для ИИ — `docs\scripts\PROMPT-rewrite-first-messages.md`). Заголовки
   `### slug` и поля `{…}` и `[…]` не менять.
3. Проверить: `… import_rewritten_scripts.py <файл>` (сухой прогон), записать: `… <файл> --apply`.
4. Собрать новую сборку. При первом запуске она обновит в базе только те тексты, которые вы не правили в приложении.

Документы: `docs/unify/` (объединение с Mini App, редизайн), `docs/mailing/` (рассылка), `docs/next/` (скорость
поиска, остановка, пачки и повторы).
