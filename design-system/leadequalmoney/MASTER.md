# LeadEqualMoney · интерфейс настольного приложения

## Направление

Рабочая программа для одного пользователя. Визуальная система следует PDF «Чек-лист по нейро-визуалу» и предоставленным скриншотам: ясная иерархия, ровные отступы, хорошая кириллица, заметные основные действия. Локальный поиск UI/UX Pro Max подтвердил пригодность плоского интерфейса для плотной панели управления; цветовая схема взята из PDF, а не из предложенной светлой палитры.

## Цвет и типографика

| Роль | Цвет |
|---|---|
| Фон | `#0c1827` |
| Боковая панель | `#0a1421` |
| Поверхность | `#132437` |
| Граница | `#294158` |
| Основной текст | `#f4f8fc` |
| Вторичный текст | `#a9bfd0` |
| Главное действие | `#65d8ff` |
| Ошибка | `#ff9da8` |

Основной шрифт: Segoe UI Variable, затем Segoe UI. Базовый размер 15 px, основной заголовок 28 px, заголовок секции 19 px. Все кнопки и поля имеют высоту не меньше 42 px. Акцент используется для одного главного действия в панели, выбора вкладки и клавиатурного фокуса.

## Взаимодействие

- Экран задачи сначала показывает источник, затем параметры, затем главное действие и историю.
- Источник медиа выбирается явно между базой и ручной ссылкой; скрытое значение другого источника никогда не отправляется.
- Адресаты кампании выбираются на том же экране, где скрипт. Недоступные для отправки карточки объясняются статусом и ссылкой на карточку.
- Результат медиа открывается как обычная папка. Повторное задание требует отдельного действия.
- Для ошибок Яндекса, отсутствия адресата, незаполненных полей и неполученного Telegram API используются конкретные сообщения, связанные с нужной задачей.
- Управление доступно с клавиатуры; видимый фокус, контраст и сокращение анимации обязательны.

## Техническая реализация

Токены и компоненты описаны в `app/desktop_ui/lem.css`, поверх базового `style.css`. Новые ресурсы не загружаются из сети, чтобы приложение работало как локальное окно.
