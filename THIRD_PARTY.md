# Сторонние компоненты

## Glass folder reference

Владелец передал описание визуальной ссылки стеклянных папок для этапа дизайна, но исходный URL, репозиторий, версия и лицензия референса не указаны. Поэтому происхождение и лицензия референса остаются **не подтверждены**.

`app/desktop_ui/glass-folder.js` и `app/desktop_ui/glass-folder.css` — локальная реализация на обычных JavaScript, HTML и CSS по предоставленным требованиям. Сторонний React/Tailwind-компонент, npm-пакет или готовый файл исходника в сборку не добавлялся. Это не является утверждением о лицензии исходного референса; для точного переноса владелец должен предоставить источник и лицензию.

Локальные шрифты Inter и JetBrains Mono поставляются отдельно в `app/desktop_ui/fonts/` вместе с текстами SIL Open Font License 1.1.
